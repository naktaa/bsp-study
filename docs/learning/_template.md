# 주제: 한 줄 부제

처음 네 섹션만 읽어도 무엇을 왜 어떻게 했는지 알 수 있게 쓴다. 기준 예시는 [06-mpu6050.md](06-mpu6050.md)다.

## 1. 한눈에 보기
- **목적:** 왜 했는가
- **기능:** 무엇을 만들었거나 연결했는가
- **직접 작성 / 가져다 쓴 것:** 직접 쓴 코드·overlay·레시피 vs 업스트림 드라이버·서브시스템
- **결과(실측):** 보드에서 확인한 대표 수치 1~2개, 상세는 6장 링크
- **범위 밖:** 하지 않은 것
- **관련 파일:** 코드·스크립트·작업 노트 링크

## 2. 구조
- 흐름 한 줄: `A → B → C`
- 필요하면 ASCII 블록도(`text` 블록, 라벨은 영어·코드 이름) + 아래에 한글 설명 1~2문장
- `계층 | 구성 요소 | 하는 일` 표

## 3. 알아야 할 개념
"왜?" 질문 5개 이내. 답은 2~4줄, 근거 소스 줄 링크.

### 왜 …?

## 4. 구현 흐름
호출·데이터 순서대로 `4-1`, `4-2` … 소제목. 각 단계: 무슨 일이 일어나고 → 코드가 무엇을 하고 → 왜 그런가.
순서가 핵심이면 `순서 | 하는 일 | 코드` 표, 레지스터·설정은 `레지스터 | 값 | 의미` 표 하나로 모은다.
코드 발췌는 블록당 15줄 이내, 나머지는 줄 링크.
