# 주제: 한 줄 부제

처음 세 섹션만 읽어도 무엇을 왜 어떻게 했는지 알 수 있게 쓴다. 복잡하게 만들지 않고, 시각 자료는 필요한 곳에만 둔다.

## 1. 한눈에 보기
- **목적:** 왜 했는가
- **기능:** 무엇을 만들었거나 연결했는가
- **결과:** 보드에서 확인한 것(실측)과 남은 것
- **관련 파일:** 코드·스크립트·작업 노트 링크

## 2. 구조
흐름 한 줄(`A → B → C`), 필요하면 ASCII 블록도(라벨은 영어), `계층 | 구성 요소 | 하는 일` 표.

## 3. 알아야 할 개념
"왜?" 질문 3~5개. 답은 2~4줄, 근거 소스 줄 링크.

### 왜 …?

## 4. 구현 흐름
데이터·호출 순서대로: 무슨 일이 일어나고 → 코드가 무엇을 하고 → 왜 그런가. 코드는 필요한 부분만 짧게 발췌하고 세부는 줄 링크로 넘긴다.

## 5. 재현
빌드 → 배포 → 실행 → 정리. 명령마다 [WSL]/[Pi]·작업 디렉터리·선행 조건, 확인할 출력.
