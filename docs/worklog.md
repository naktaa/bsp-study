# 현재 진행 상태

## 현재 단계
3 — 사용자/커널 경계의 문자 디바이스 실습 계획 설명 전. 진행 순서는 1 → 7 → 2까지 완료했으며 기존 번호를 유지한다.

## 완료 요약
- 1: WSL에서 ARM64 사용자 프로그램 크로스 빌드·Pi 실행 및 종료 상태 0 확인.
- 7: 커널 6.18.59-v8-bsp-study01 크로스 빌드·설치·SSH 부팅 확인, 기존 ext4 루트 유지. 백업과 기존 커널 복귀 절차 준비(복귀 시험 미수행). 화면 미출력은 overlay 매핑 누락 복구 후 사용자 정상 출력 확인.
- 2: 모듈 Makefile 작성·크로스 빌드·clean·증분 빌드와 Pi 로드·해제 확인. loaded/unloaded 로그 및 lsmod 등록·제거 확인.

## 막힌 점·미확인
- 화면 장애는 해결됨. 최종 config.txt 전문·복구 후 커널 버전 재확인, 보완한 정상 배포 절차 전체 재실행은 미확인·미수행이며 상세 문서에 구분했다.
- 0단계의 센서 실물 모델·전원·배선은 미확인. 관련 실습 전 보완한다.

## 다음 작업
다음 보드 확인 시 최종 부팅 설정과 복구 후 버전을 보완하고, VEDA 대응 코드와 문자 디바이스 실습 계획을 설명한다. 문서 검증을 위한 재빌드·재설치는 하지 않는다. 코드 수정·빌드·보드 실행은 사용자가 직접 한다.
